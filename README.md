# Arc Storage Contract

A simple Storage smart contract built with Solidity and Foundry, deployed on Arc Testnet.

## Features
- Store a uint256 value
- Update value using setNumber()
- Read value using getNumber()

## Tech Stack
- Solidity
- Foundry
- Arc Testnet
